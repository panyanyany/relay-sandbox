# 终端直连：历史提纲与统一输入修订提纲

历史首轮：D1–D18提纲已确认，实际执行及失败见tasks.md/e2e.md。2026-11-07新增D19/D20后用户再次选择完整流程；本轮修订提纲在末节，已确认，不开始第三轮分页补丁。

## 已确认的架构边界

- 替换终端与 Webcoding 的宿主协调 AI；外部 MCP 宿主委派工作流保留。
- 共享身份、事件与忙碌准入由同一会话控制层维护，不记录客户端控制权。
- Agent 适配器保留各自原生历史；真实跨入口续接、忙碌状态及原生界面透传必须验证。
- 独立审查控制层固定证据并复用既有配置、审核 Schema、审计语义及用户报告。
- 无专用常驻 daemon；任务自有后台进程允许，普通前端断开不等于停止开发。
- 只对齐记录不是功能完成证据，当前实现尚未满足以上新行为。
