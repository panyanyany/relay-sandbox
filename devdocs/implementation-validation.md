## 已修复的问题

- 类型检查发现 tar-stream 与 dockerode 流类型差异，改为标准 PassThrough 桥接。
- 超时停止容器时，输出流先结束会被误认普通退出；增加超时停止状态核对。
- 候选写入可能遇到宿主新增的链接父目录；候选检查与应用器均拒绝链接祖先。
- 空目录原先只复制而未进入交付；现已进入清单、摘要、差异和应用测试。
- 最终检查原先复用开发容器；改为新建检查容器，保留正常返工工作区。
- 恢复测试的重复删除暴露清理非幂等；仅对已不存在的资源接受 404，其他错误继续抛出。
- TypeScript 6 构建要求显式 rootDir；现已固定输出目录并禁止错误产出。
- 拆分开发适配器时出现语法错误；已补齐结构并重新运行检查，未将失败记录为通过。

## MCP 能力发现与有界等待（2026-11-02）

新增 `get_capabilities`，声明实际工作流、有界等待、查询、结构化审核、部分审计和用户通知限制。初始化说明引导宿主发现能力，每个工具提供中文用途与步骤说明。`eventHooks`、`pushNotifications`、`nativeMcpTasks`、`hostWakeup` 均明确为不支持。

`get_task` 在原任务字段外增加 `revision`。`wait_task` 使用该游标等待最新快照变化，默认 25 秒、最多 55 秒；取消只取消等待，不停止任务。实现使用服务端文件轮询，不调用模型，不保证保留所有中间状态。

单元测试验证同状态证据更新、旧游标立即返回、无更新超时、取消不改变任务，以及非法参数和不存在任务报错。实际 SDK stdio 测试验证初始化指引、工具描述和能力发现、读取游标、等待超时及另一个 MCP 调用更新任务后返回变化。常规测试共 19 项通过，lint、类型检查与构建通过。当前为 CLI/MCP，无网站重启目标。
